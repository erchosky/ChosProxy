# Audit — 2026-11-11 (Milestone 17: 1.0 Core feature discovery audit)

Before tagging 1.0, every **Core** row of the
[parity matrix](../BURP_PARITY_MATRIX.md) was re-checked (addendum §124). Core
covers Proxy, Intercept, HTTP history, Repeater, Site map, WebSockets,
Decoder, Comparer and Organizer (ROADMAP "Product tiers"), plus the message
editor, projects, settings and packaging they rely on. Each row is
classified as IMPLEMENTED, PARTIAL, PLANNED or NOT APPLICABLE. A row that is
not complete names what is missing and where it goes.

The reference tool's capabilities come from the parity addendum and the
matrix. A fresh pass against the reference's current online documentation
is part of the M32 parity audit; this audit did not re-download it.

## Known limitations

* Sorting HTTP history by a column without an index (length, duration,
  MIME, path) takes about 120 ms per page on 100 000 exchanges.
* WebSocket hits in global search only honour "in scope only"; the other
  history filters apply to HTTP traffic.
* Copy as curl produces bash/zsh syntax; binary bodies use `$'…'`, which
  plain `sh` (dash) does not understand.
