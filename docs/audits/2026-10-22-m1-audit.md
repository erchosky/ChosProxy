## 2. Code review (M0/M1)

Fixed in this audit (with regression tests):

| Severity | Finding | Fix |
|---|---|---|
| Medium | History keyboard navigation used a remembered row *index*; with newest-first order, new traffic shifts rows, so ↑/↓ could jump to an unrelated request. | Selection resolved by exchange id (`indexOfId`). |
| Medium | Opening another project while History was visible reset the list without reloading it → existing history appeared empty. | `reset()` reloads page 0. |
| Low | "Clear filters" from the empty state left the old text in the search box, and the debounce re-applied it. | Search box follows external filter changes. |

Reviewed, no change needed:

* SQL: only fixed fragments + bound parameters; `LIKE` wildcards escaped; limit/offset are validated integers.
* Untrusted content: shown only as text (CodeMirror/React text nodes); lint bans raw HTML injection; strict CSP; minimal Tauri capabilities.
* Resource bounds: 64 KiB heads, 256 headers, capped capture per message, bounded storage and event queues, 120 s idle timeouts, 32 MiB display decode limit, 1 MiB sniff limit.
* Secrets: logs contain no headers/bodies; `Proxy-Authorization` and `Proxy-Connection` never forwarded upstream.
* Files: config/projects `0600`, dirs `0700`, atomic writes, unusable config preserved.

Known limitations (tracked):

* A listener on `0.0.0.0` does not recognise requests to the machine's LAN IP as self-requests (only relevant with remote access enabled) — THREAT_MODEL.
* Temporary projects left by a crash are not cleaned up automatically — crash recovery is M31.
* Adding a new listener with "start with project" only starts it on the next project open or via Start.

## 3. Dependency advisories

* `pnpm audit`: no known vulnerabilities.
* `cargo audit` (489 crates): **no vulnerabilities**. 8 warnings, all transitive through Tauri 2 / GTK 3 bindings, none reachable from ChosProxy code:
  * unmaintained: `proc-macro-error`, `unic-*` (via `urlpattern` ← `tauri-utils`), GTK 3 Rust bindings family;
  * unsound: `glib::VariantStrIter` (RUSTSEC-2024-0429) — not used by Tauri's code paths we exercise or by ChosProxy.
  * Action: follow Tauri updates; re-check every milestone. CI now runs `cargo audit` and `pnpm audit --prod`.

Packaging defects found and fixed during this audit:

* Debian package was named `chos-proxy` with an invalid `Maintainer` →
  repacked as `chosproxy` with a valid maintainer field.
* AppImage creation failed: `appimagetool` rejects the non-`X-` Kali
  category → the AppImage uses a freedesktop-compliant desktop entry; the
  `.deb` keeps the Kali category. CI had the same latent failure.
* Misplaced `256x256@2` icon directory → `@2x` icon removed from the Linux set.
* Building on ARM hosts under x86_64 emulation cannot execute AppImage
  runtimes ("Exec format error") → builder pre-extracts the linuxdeploy
  plugin. Emulation-only; native builds are unaffected.

macOS (Apple Silicon, release build): `.app` ad-hoc signed (no Apple
Developer ID), `.dmg` built with `hdiutil`; launched, captured traffic
through the proxy, temporary project deleted on quit.

Not verified: a graphical Kali desktop session (menu placement seen by a
user), Kali on real x86_64 hardware, macOS Gatekeeper behaviour after
downloading from the internet.
