## Findings fixed during this milestone

| Severity | Finding | Fix |
|---|---|---|
| High | Saving listeners from the UI sent a config without the new `tls` section → the HTTPS policy would have been reset | UI keeps all other sections when saving listeners |
| Medium | Launching a browser whose executable disappeared could report success in some environments (seen in the Kali container) | Explicit executable check before launch; regression test |
| Low | Google Chrome background traffic floods history | Additional Chromium flags; scope filtering in M5 will hide the rest |

## Known limitations

* HTTP/2 is not intercepted yet (ALPN offers HTTP/1.1; browsers fall back).
* Apps with certificate pinning need a passthrough entry.
* Lab browser on a graphical Kali desktop with Kali's Chromium not yet checked
  by hand (same flags, verified with Chrome on macOS).
* Running ChosProxy as root on Linux requires `--no-sandbox` for Chromium;
  the UI warns.
